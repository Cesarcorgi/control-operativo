# Control Operativo

App web para que choferes y cargadores llenen su control operativo diario desde el celular.

- **Se instala** como app desde Chrome (Android) o Safari (iPhone → Compartir → Agregar a inicio).
- **Funciona sin señal** una vez que se abrió con internet.
- **Guarda todo en el teléfono** mientras se escribe; nada se sube a internet.
- **Enviar resumen** arma el reporte del día para mandarlo por WhatsApp.

Enlace: https://cesarcorgi.github.io/control-operativo/

Para publicar una versión nueva: cambiar `VERSION` en `sw.js` (y el número en `index.html`). Los teléfonos la reciben la segunda vez que abren la app.
